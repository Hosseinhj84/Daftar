## `01` · ایده

### وقتی عددها زیاد می‌شوند، تصویر کلی نباید گم شود.

فریلنسرها و کسب‌وکارهای کوچک معمولاً اطلاعات مالی خود را در چند جای مختلف نگهداری می‌کنند؛
فاکتورها یک‌جا، هزینه‌ها جای دیگر و اطلاعات مشتریان در فایل‌ها و یادداشت‌های مختلف.

**دفتر درآمد** برای جمع کردن همین قطعات ساخته شده است.

یک محیط ساده برای اینکه بتوانید:

```text
مشتری
   ↓
فاکتور
   ↓
درآمد / هزینه
   ↓
گزارش
   ↓
تصویر واضح‌تر از وضعیت مالی
```

بدون اینکه برای ثبت یک هزینه ساده مجبور شوید با یک نرم‌افزار حسابداری سنگین دست‌وپنجه نرم کنید.

# `05` · معماری

دفتر درآمد از دو بخش اصلی تشکیل شده است:

```text
                         DAFTAR
                           │
             ┌─────────────┴─────────────┐
             │                           │
         FRONTEND                    BACKEND
             │                           │
          React                       Django
             │                           │
       React Router                Django REST API
             │                           │
         Axios                      Simple JWT
             │                           │
             └─────────────┬─────────────┘
                           │
                       DATABASE
                           │
                  ┌────────┴────────┐
                  │                 │
                SQLite          PostgreSQL
```

### Frontend

رابط کاربری با React ساخته شده و مسئول نمایش اطلاعات، تعامل کاربر و ارتباط با API است.

### Backend

Django و Django REST Framework منطق سمت سرور، احراز هویت و دسترسی به داده‌ها را مدیریت می‌کنند.

### Database

برای اجرای محلی SQLite و برای محیط‌های سروری PostgreSQL در نظر گرفته شده است.

# `08` · راه‌اندازی

## Requirements

قبل از شروع، موارد زیر را داشته باشید:

```text
Python 3.11+
Node.js 18+
npm
Git
```

---

## Backend

ساخت محیط مجازی:

```bash
python -m venv venv
```

### Windows

```powershell
.\venv\Scripts\Activate.ps1
```

یا:

```bat
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

---

## Environment

یک فایل `.env` بر اساس `.env.example` بسازید:

```env
SECRET_KEY=replace-with-a-random-secret-key
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

> فایل `.env` نباید در مخزن عمومی قرار بگیرد.

---

## Database

```bash
python manage.py migrate
```

ساخت حساب مدیریتی:

```bash
python manage.py createsuperuser
```

---

## Run Backend

```bash
python manage.py runserver
```

Backend:

```text
http://127.0.0.1:8000
```

---

## Run Frontend

در ترمینال جداگانه:

```bash
cd frontend
npm install
npm run dev
```

Frontend:

```text
http://localhost:5173
```

> `runserver` و `npm run dev` برای توسعه هستند و برای استقرار عمومی توصیه نمی‌شوند.
